# v1.2.1 — 對外網域改為 2026s2ctrees.vercel.app

這一版沒有新功能，只把**對外網域**從 `old-trees-mylearning.vercel.app` 換成 **`2026s2ctrees.vercel.app`**，並讓所有相關設定與文件跟上。

## 改了什麼

| 項目 | 內容 |
|---|---|
| `vercel.json` | 兩處 `Access-Control-Allow-Origin` 改為新網域 |
| `lib/http.js` | CORS 白名單加入新網域（舊網域保留，讓舊連結與已印出的 QR 仍可用） |
| QR 碼 | 新產生的 QR 內容與 SVG 註解改用新網域 |
| `README.md` | 網站徽章與手機安裝說明 |
| 測試 | `card`／`qr`／`security-headers`／`pages-deploy` 的期望值同步更新 |
| Wiki | 主站與世界地圖連結 |
| Cloudflare Pages 鏡像 | `functions/api/[[route]].js` 的上游改指新網域 |

## 舊網域怎麼處理

`old-trees-mylearning.vercel.app` 已設為 **307 轉向**到新網域：

```
$ curl -I https://old-trees-mylearning.vercel.app/
HTTP/2 307
location: https://2026s2ctrees.vercel.app/
```

也就是說：**已印出的 QR 碼、老師手上的舊連結都不會壞**，會自動跳到新站。

## 驗證

```
GET https://2026s2ctrees.vercel.app/            → 200
GET …/api/health                                → 200，data_source=neon，tree_count=658
access-control-allow-origin                     → https://2026s2ctrees.vercel.app
CSP                                             → 與 v1.2.0 相同（script-src 'self'，未放寬）
舊網域                                          → 307 → 新網域 → 200
npm test                                        → 417 全過
npm run check                                   → 通過
```

## 升級注意

- 沒有資料庫或 API 行為變更，Neon 不需動作。
- Service Worker 的版本升到 `v1.2.1`，瀏覽器下次開啟會自動更新快取。
- 如果你把網站加到手機主畫面，圖示仍有效（manifest 用相對路徑）。
